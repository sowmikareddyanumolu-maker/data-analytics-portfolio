E-Commerce Sales & Profit Analysis Dashboard

📊 Project Overview

An interactive E-Commerce Sales & Profit Analysis Dashboard built using Microsoft Excel to analyze sales performance, profitability, customer behavior, regional performance, product performance, and payment trends.

🛠️ Tools & Skills

- Microsoft Excel
- XLOOKUP
- Excel Formulas
- PivotTables
- PivotCharts
- Slicers
- KPI Dashboard
- Data Analysis
- Business Insights

📈 Key Analysis

The project analyzes:

- Product-wise revenue and profit
- Product profit margins
- Regional sales and profitability
- Category performance
- Payment method performance
- Monthly revenue and profit trends
- Customer revenue and profitability

💡 Key Business Insights

- Running Shoes generated the highest overall revenue and total profit.
- USB-C Cable had the highest average profit margin.
- North generated the highest revenue and total profit among regions.
- Electronics was the strongest category in terms of revenue and profit.
- UPI generated the highest revenue among payment methods.
- October recorded the highest revenue, while January recorded the highest profit.

🎯 Objective

The objective of this project was to transform raw e-commerce transaction data into an interactive dashboard and generate actionable business insights to support data-driven decision-making.
